## 4. 已知问题（接手先修这些）

单元测试当前 **5 失败**（`pytest tests/unit`）：

1. **`test_config_validation.py::test_template_example_only_is_not_usable_for_run`**
   现象：模板 `runtime.example.json` 含 `"example_only": true`，但 `validate_config()` 后 `usable_for_run` 返回 `True`。手动调试复现：`valid:True, usable:True`。
   修复方向：`RuntimeConfig` 里有 `example_only` 字段但值没有传进去（可疑点：`_parse_config` 或模板加载路径把字段丢了），查 `config/validation.py::_parse_config` 与 `schema.py::RuntimeConfig`。

2. **`test_manifest_validators.py::test_map_rejects_placeholder_zero_hash`**
   现象：`"0"*64` 通过了 map manifest 校验。
   修复方向：`manifests/validators.py::validate_map_manifest` 只查了 sha256 正则；加全零拒绝（models-lock 那边已有同样的检查可以抄）。

3. **3 个 report completeness 失败**（`test_report_completeness.py` 的 fully_evidenced / optional_skip / legitimate_fail）
   根因：`reporting/completeness.py` 里"case mode 必须在 requested_modes 内"的检查太严格。按验收规范，mock 运行的报告**合法包含** P0-ENV（mode=hardware、BLOCKED）作为 out-of-scope 用例——`commands/accept.py` 生成的正是这种结构，所以这个检查还会让 accept 自检误报。
   修复方向：去掉/放宽该检查（out-of-scope 用例允许存在；run_status 聚合已只统计 requested 模式内的用例，保住语义）。同时 `accept.py::_malformed_reports()` 里的 `"mode-not-requested"` 样本设计要跟着改（可换成"required 用例 NOT_RUN 但 phase_gate=PASS"这类真违规）。

4. **集成测试完全没跑过**（`pytest tests/integration`）。已知存疑点：`test_fault_reject_next` 期望 `GatewayConnectionError`，但 gateway 对 reject_next 返回的是 503 + envelope，客户端会抛 `GatewayError(ROBOT_UNREACHABLE)` 而不是连接错误——跑之前先把这个断言改成后者。

5. `accept --phase P0` **没跑过**，跑之前先把 1–4 修完，否则 P0-REPORT 门槛会因 completeness bug 失败。

另有两处非阻塞小问题：
- `cli.py::cmd_doctor` 里 robot doctor 未传 `--read-only` 报错文案是"requires --read-only in P0"，行为正确。
- `processes.py::status` 里变量 `report` 在 config 不存在时未定义（`report.config` 引用）——config 存在时正常，但顺手加个初始化。

## 5. 关键设计决策（改代码前先读）

- **mock 隔离是双层的**：配置校验拒绝（mock profile + 非 loopback gateway_url）+ `GatewayClient` 构造时拒绝。P0-ISOLATION 的 5 个注入样本两端都必须拒。改任何一层都要同步另一层和测试。
- **mock 标记**：所有 mock gateway 响应带 `X-Spatial-Source: mock` 头 + `data.source=="mock"`；调试页显示黄色 MOCK 横幅。
- **stop 与 cancel 分离**：`/v1/safety/stop` 永远重执行（不带 Idempotency-Key）、锁存、取消活动导航；`cancel` 只取消单个导航。arm 需要 `clear_stop=true` 才能解除锁存。
- **租约重放**：`lease sequence` 必须严格递增，重放返回 LEASE_EXPIRED。
- **报告结构**：`run_status` 只聚合本次请求模式的用例；`phase_gate_status` 聚合全阶段（P0 需要 P0-ENV 的 hardware 只读证据才能 PASS）。mock 报告里 P0-ENV 是 BLOCKED + blocker 文案，这是设计如此，不是 bug。
- **trials.jsonl 只追加**，永不改写失败记录（`reporting/report.py::append_trial`）。
- **验证器三档**：valid / template（example_only 骨架，可作文档但不可用于运行）/ invalid。
- 车端 SSH：**只允许 BatchMode 密钥认证**，密码绝不上命令行。当前机器人不可达（见 §6）。
