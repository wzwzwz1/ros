# P5：中文语音与自定义唤醒词

## 目标与前置条件

第一版 P5A：自定义唤醒 → 一句中文任务 → 现有 Agent → 实车执行 → 语音播报。Mac 运行语音模型，小车采集/播放。P4 全链路已通过；早期音频检查可在 P0/P1 提前做。

用户尚未最终指定唤醒词。默认候选“你好小轮”仅用于开发样例，不代表用户已选定；P5 开始时从项目配置读取，若无选择可先用该候选开发并在实际使用前明确展示当前词。换词不要求重写程序。

## 按顺序执行

1. **P5.1 音频入口**：确认车载模块型号、原始 PCM/ALSA 设备、通道、采样率、权限和播放设备。只有厂家命令识别输出、无法取得原始声音时，先解决音频入口或提出具体硬件缺口，不假装支持自由语音。
2. **P5.2 音频传输**：实现有序限长音频流、格式协商、掉帧和重连；保留500ms pre-roll。Mac麦克风可用于离线开发，最终验收必须使用车载麦克风。
3. **P5.3 KWS**：集成 sherpa-onnx 中文关键词模型；配置中文唤醒词经 tokenizer 生成关键词文件，阈值可配置。启动加载模型，确认“改词”实际改变检测器。
4. **P5.4 会话/VAD**：实现 IDLE/提示/收听/转写/派发/执行/播报状态，录音15秒上限、800ms静音结束、5秒未说话回IDLE；阻止同一 utterance 创建多任务。
5. **P5.5 ASR**：SenseVoiceSmall 量化 ONNX，第一版按句转写。保留识别原文与规范化文本，不能消除“不/别/取消”等否定；低可信或关键目标不确定时询问。
6. **P5.6 TTS**：MeloTTS中文ONNX生成音频，经车端播放接口输出；记录实际播放完成/错误。任务事实由执行器事件决定，失败不能播报为成功。
7. **P5.7 停止优先级**：导航期间且没有TTS播放时，本地 stop 关键词不需要普通唤醒，直接触发控制通道；普通指令不直接抢占活动导航。stop detector 与云 API 无关。
8. **P5.8 播报门控**：TTS期间关闭普通唤醒/指令派发；播放结束再放开。基础版不承诺播报期间语音打断，调试页停车始终可用。
9. **P5.9 声学数据**：主用户在1m/3m、静止/电机噪声条件录音；构建独立命令测试集、第二唤醒词样本和2小时真实负样本。记录增益、音量、噪声条件、设备与模型hash。
10. **P5.10 全链路与资源**：完成10次语音导航和30分钟并行服务测试；分析漏唤醒、误唤醒、关键字错识、延迟和自触发。

## 必须交付

- `voice/` 的 audio、KWS、VAD、ASR、TTS、session 模块和可替换适配接口。
- 可配置唤醒词与重启持久化、stop关键词、本地模型下载和版本记录。
- 语音与文字复用 Task API，不新增第二套导航业务。
- 音频数据/转写/任务的对应关系、声学验收报告、资源报告。
- 当前范围明确：轮流说话、停车接收普通任务、导航中非播放状态的停止关键词；没有通过扩展验收就不宣传全双工。

## 部署与验收

```bash
./scripts/project models fetch --group voice
./scripts/project test --level unit
./scripts/project test --level integration --profile mock
./scripts/project accept --phase P5 --mode replay
./scripts/project accept --phase P5 --mode hardware --session <session_id>
```

`P5-END2END` 同时使用真实 DeepSeek API；报告必须单独标注依赖与耗时。单纯播放录音做转写不能算真实唤醒/车载端到端验收。P5-AUDIO～P5-RESOURCE 门槛见 [验收规范](../acceptance.md)。

## 失败处理

- 误唤醒：先检查门控、录音质量与阈值，再更换词；调参后更换独立验收集或保留冻结集做回归，不能删掉失败片段。
- ASR 对象/否定错误：保留原文，要求澄清或取消，禁止按错误目标盲目发车。
- 音频断流/无声/过长：回到明确状态，不把残留缓冲拼成新指令。
- TTS 失败：在界面报告，任务执行结果保持真实，不重复导航。
- 车端处理占用超预算：KWS/VAD继续放Mac，不擅自上车跑大模型。

## P5B/P5C 可选扩展（不影响 P5A 的完成判定）

- P5B：多轮会话、自然打断、播报期间停止，增加 AEC/回声路径测试与双讲误识评测。
- P5C：运动中远场普通任务、多人/口音泛化、唤醒迁移车端；重新评估噪声、资源和断网行为。

这些扩展需单独任务范围与验收 suite；不能把本文件的未来条目误标成当前必需实现。
